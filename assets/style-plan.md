# Style Plan — ThetaIO Grok Search README Assets

## 通用风格系统

- **背景**：近黑 `#090909` 至 `#101010`，带极轻微纸张颗粒/哑光质感，无渐变光晕
- **线路**：1px 细灰线 `#2a2a2a`~`#3f3f46`，直角折线布线（正交布线，非曲线），节点处小方块
- **节点面板**：`#101010`/`#18181b` 表面，1px `#27272a` 边框，3–6px 小圆角
- **高亮点**：钩子绿 `#b9c7a7` 直径 6–8px 状态点，配文字标签；用量极少
- **文字**：Outfit 大写宽字距（系统标签，11px 感），等宽（代码/路径/模型 ID），Plus Jakarta Sans 中等字重（主标题 540）
- **排版**：编辑式、左对齐、档案感；大量留白（品牌区 96–160px 感）
- **禁止项**：紫蓝渐变、霓虹、发光、光球、3D 渲染、抽象 AI 人脸、玻璃拟态、彩色图标块、大圆角浮动卡片

## 01 hero.png（16:9）

- 主体：一张基础设施线路图。左侧一个标注 `X` 的信源节点，右侧一个标注 `WEB` 的信源节点；两条正交灰线汇入中央一个较大的系统面板节点，面板标注 `THETAIO` / `POST /V1/RESPONSES`，从中央向下引出一条线到 `URL_CITATION` 输出节点
- 中央面板顶部有一个绿色状态点 + `ONLINE`
- 背景近黑哑光，细线路，节点小圆角，无发光
- 左上角极小大写标签 `GROK SEARCH`，右下角极小标签 `MODEL: GROK-4.3`
- 光线：均匀、低对比、哑光，无光源戏剧性

## 02 pipeline.png（16:9）

- 主体：四段横向管线，正交连线：`CLIENT` → `GATEWAY` → 分叉为 `X_SEARCH` / `WEB_SEARCH` 两条并行轨道 → 汇合到 `CITATIONS`
- 每条轨道用等宽字体标注，分叉处两个小节点
- 线路为细灰实线，其中一条可略带虚线纹理表示流向
- 背景 `#090909`，面板 `#101010`，边框 `#27272a`
- 无标题大字，仅系统标签

## 03 mono-dark.png（1:1）

- 主体：两张上下堆叠的系统面板卡片（直角/小圆角），上卡标题 `X_SEARCH`，下卡标题 `WEB_SEARCH`
- 每张卡内以等宽小字列出示意字段：`query: from:thsottiaux`、`mode: Latest`、`limit: 10`（x 卡）；`query: latest AI news`（web 卡）
- 右上角各一个状态点，x 卡为绿色 `ONLINE`
- 纸张灰细边框，无阴影，哑光

## 04 status.png（3:1）

- 主体：一条细长的运行状态面板，横向分隔线组织三列数据，等宽字体
- 左：`X_SEARCH_CALLS  3`，中：`WEB_SEARCH_CALLS  0`，右：`STATUS  ONLINE`（绿点）
- 顶部极小区号 `USAGE / SERVER_SIDE_TOOL`
- 近黑背景，细灰线，克制的数字化档案感

## 画幅与尺寸

- 尺寸档位统一 `2K`
- 比例写进提示词：hero/pipeline 为 16:9；mono-dark 为 1:1；status 为 3:1
